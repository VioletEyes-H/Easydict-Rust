# 划词快捷键翻译方案

## 需求

用户在任意应用中选中一段文字，按下全局快捷键后，翻译应用弹出并自动填入选中的内容。

## 核心问题

Tauri v2 **无法直接读取其他应用中的选中内容**。Tauri 运行在一个 WebView 里，没有系统 API 可以直接拿到"当前被选中的文本"。

因此需要借助**系统剪贴板**作为桥梁。

## 推荐方案：全局快捷键 + 模拟复制 + 内容差异即时恢复

流程：

```
用户选中文本 → 按下全局快捷键（如 Ctrl+Shift+T）
                         ↓
      Rust 保存原始剪贴板内容
                         ↓
      Rust 模拟按 Ctrl+C / Cmd+C（写入剪贴板）
                         ↓
      每 5ms 轮询检测剪贴板是否变化
      （通常 10~30ms 内检测到写入）
                         ↓
      读取变化后的内容 = 用户选中文本
                         ↓
      立即恢复原始剪贴板（覆盖窗口 < 50ms）
                         ↓
      前端弹出翻译窗口并填入文本
```

核心改进：**内容差异轮询替代固定 sleep**。不等到 150ms 后才读，而是每 5ms 检查一次，一旦内容变化立即读取并恢复。覆盖窗口从 350ms 压缩到几十毫秒，用户几乎无感知。

## 1. 注册全局快捷键

Tauri v2 使用 `global-shortcut` 插件。

```rust
// src-tauri/src/lib.rs
use tauri::Manager;
use tauri_plugin_global_shortcut::{GlobalShortcutExt, Shortcut};

pub fn run() {
    tauri::Builder::default()
        .plugin(tauri_plugin_global_shortcut::Builder::new().build())
        .plugin(tauri_plugin_clipboard_manager::init())
        .setup(|app| {
            let shortcut = Shortcut::new(
                Some(tauri_plugin_global_shortcut::Modifiers::CONTROL),
                tauri_plugin_global_shortcut::Code::KeyT,
            );

            let app_handle = app.handle().clone();
            app.global_shortcut().register(shortcut, move || {
                let _ = app_handle.emit("translate-selection", ());
            })?;

            Ok(())
        })
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

### 需要安装的依赖

在 `src-tauri/Cargo.toml` 中添加：

```toml
[dependencies]
tauri-plugin-global-shortcut = "2"
tauri-plugin-clipboard-manager = "2"
enigo = "0.2"
```

前端也需要安装对应的 npm 包：

```bash
yarn add @tauri-apps/plugin-global-shortcut @tauri-apps/plugin-clipboard-manager
```

## 2. Rust 端模拟复制 + 即时恢复剪贴板

使用 `enigo` 模拟按键，通过**内容差异轮询**替代固定 sleep，在检测到剪贴板变化后立即恢复，将覆盖窗口压缩到毫秒级。

> **轮询生命周期**：轮询仅在快捷键触发后、命令执行期间运行（最长 200ms），函数返回即结束。**不是常驻后台线程**，不占用平时资源。

```rust
// src-tauri/src/lib.rs
use tauri::Manager;
use tauri_plugin_clipboard_manager::ClipboardExt;
use enigo::{Enigo, Key, KeyboardControllable};
use std::{thread, time::{Duration, Instant}};

/// 模拟 Cmd/Ctrl+C 读取选中文本，通过内容差异检测即时恢复剪贴板。
///
/// 流程：
///   1. 保存原始剪贴板内容
///   2. 模拟 Cmd/Ctrl+C
///   3. 每 5ms 轮询剪贴板，内容一旦变化（≠原始）即判定为选中文本已写入
///   4. 立即写回原始内容，覆盖窗口仅几十毫秒
///
/// 边缘情况：若选中文本恰好等于原始剪贴板内容（极罕见），
/// 轮询会超时返回空字符串。此时可提示用户重试。
#[tauri::command]
fn simulate_copy_and_read(app: tauri::AppHandle) -> Result<String, String> {
    // 1. 保存原始剪贴板
    let original = app.clipboard().read_text().unwrap_or_default();

    // 2. 模拟复制
    let mut enigo = Enigo::new();

    #[cfg(target_os = "macos")]
    {
        enigo.key_down(Key::Meta);
        enigo.key_click(Key::Layout('c'));
        enigo.key_up(Key::Meta);
    }
    #[cfg(not(target_os = "macos"))]
    {
        enigo.key_down(Key::Control);
        enigo.key_click(Key::Layout('c'));
        enigo.key_up(Key::Control);
    }

    // 3. 轮询等待剪贴板内容变化（不等固定时间）
    let deadline = Instant::now() + Duration::from_millis(200);
    let mut selected = String::new();
    while Instant::now() < deadline {
        let current = app.clipboard().read_text().unwrap_or_default();
        if current != original {
            selected = current;
            break;
        }
        thread::sleep(Duration::from_millis(5));
    }

    // 4. 立即恢复原始剪贴板（覆盖窗口 = 步骤 3 检测耗时，通常 10~30ms）
    if !original.is_empty() {
        let _ = app.clipboard().write_text(original);
    }

    Ok(selected)
}
```

> **注意**：`enigo` 在 macOS 上模拟按键需要系统授予**辅助功能**或**输入监控**权限。首次使用时会弹出系统权限申请。

## 3. 前端监听快捷键并读取剪贴板

```javascript
// src/composables/useSelectionTranslate.js
import { listen } from '@tauri-apps/api/event'
import { invoke } from '@tauri-apps/api/core'

// Rust 端 simulate_copy_and_read 已内置剪贴板保存/恢复，
// 前端只需一次 invoke 即可拿到选中文本。
export function useSelectionTranslate(callback) {
  return listen('translate-selection', async () => {
    try {
      const selectedText = await invoke('simulate_copy_and_read')

      if (selectedText?.trim()) {
        callback?.(selectedText.trim())
      }
    } catch (error) {
      console.error('划词翻译失败:', error)
    }
  })
}
```

在 `App.vue` 或主入口中注册监听：

```javascript
// src/App.vue
import { onMounted, onUnmounted } from 'vue'
import { invoke } from '@tauri-apps/api/core'
import { useSelectionTranslate } from '@/composables/useSelectionTranslate.js'
import { useTranslateStore } from '@/stores/translate.js'

const translateStore = useTranslateStore()
let unlisten = null

onMounted(async () => {
  unlisten = await useSelectionTranslate(async (text) => {
    // 显示窗口并聚焦
    await invoke('show_translate_window')
    translateStore.setInput(text)
    translateStore.translate()
  })
})

onUnmounted(() => {
  unlisten?.()
})
```

## 4. 显示并聚焦翻译窗口

```rust
#[tauri::command]
fn show_translate_window(app: tauri::AppHandle) {
    if let Some(window) = app.get_webview_window("main") {
        let _ = window.show();
        let _ = window.set_focus();
    }
}
```

不要忘记在 `invoke_handler` 中注册所有 command：

```rust
.invoke_handler(tauri::generate_handler![simulate_copy_and_read, show_translate_window])
```

## 5. 各平台注意事项

| 平台 | 实现方式 | 注意点 |
|------|---------|--------|
| **Windows** | `enigo` 模拟 `Ctrl+C` + 剪贴板 | 一般无需额外权限 |
| **macOS** | `enigo` 模拟 `Cmd+C` + 剪贴板 | 第一次使用会弹出**辅助功能权限**申请，需在"系统设置 → 隐私与安全性 → 辅助功能"中允许 |
| **Linux** | `enigo` 模拟 `Ctrl+C` + 剪贴板 | X11 下正常；Wayland 下全局快捷键和剪贴板访问受限，可能需要额外处理或限制功能 |

## 6. 需要考虑的副作用

### 覆盖用户剪贴板

模拟 `Cmd/Ctrl+C` 必然将选中文本写入系统剪贴板。**无法真正拦截**（需要 hook 系统 API 并注入其他进程），但可以通过**内容差异轮询 + 即时恢复**将覆盖窗口压缩到几十毫秒。

**工作原理**：

```
1. 保存原始内容  ── read_text() 保存为 original
2. 模拟 Cmd/Ctrl+C  ── 系统将选中文本写入剪贴板
3. 轮询检测（5ms 间隔）  ── read_text() 与 original 比较
   一旦不同 → 判定写入完成（通常 10~30ms）
4. 立即恢复  ── write_text(original)
```

**为什么用内容差异而非固定 sleep**：

| 方法 | 覆盖窗口 | 检测延迟 |
|------|---------|---------|
| 固定 sleep 150ms + 200ms | ~350ms | 始终等待完整时间 |
| 内容差异轮询 5ms | ~10~50ms | 写入即检测，不空等 |

**为什么在 Rust 端处理**：

- 所有剪贴板操作在同一个同步线程，轮询时序精确可控
- 不会因 JS 事件循环延迟导致检测滞后
- `ClipboardExt` 直接使用系统 API，比 `navigator.clipboard` 更可靠

**边界情况**：

| 场景 | 处理方式 |
|------|---------|
| 原始剪贴板为空 | 不恢复（避免写空字符串） |
| 选中文本 == 原始内容（极罕见） | 轮询超时返回空，用户可重试 |
| 200ms 内未检测到变化 | 超时返回空字符串（可能用户未选中文本） |
| 恢复期间用户手动复制 | 极小时间窗口（< 50ms），几乎不可能发生 |

### 全局快捷键冲突

`Ctrl+T` 可能与浏览器"新建标签页"等快捷键冲突。建议：

- 提供快捷键自定义设置
- 默认值选择不太常用的组合，如 `Ctrl+Shift+T` 或 `Alt+T`

## 7. 替代方案：macOS 辅助功能 API（不推荐作为第一版）

macOS 上可以用 `objc2` 直接读取选中内容，不用修改剪贴板。但存在以下问题：

- 需要用户授予**辅助功能权限**
- 很多应用（尤其是浏览器和 Electron 应用）不暴露选中内容
- 代码复杂，维护成本高

只有在"绝对不能覆盖剪贴板"的场景下才考虑此方案。

---

## 8. 推荐实施顺序

1. 安装 `global-shortcut`、`clipboard-manager` 插件和 `enigo`
2. 在 Rust 中注册全局快捷键，触发事件到前端
3. 实现 `simulate_copy_and_read` 命令（内置剪贴板保存 → 模拟复制 → 读取 → 恢复）
4. 前端监听事件，调用 `invoke('simulate_copy_and_read')` 获取选中文本
5. 显示主窗口并填入文本进行翻译
6. 增加快捷键配置项
